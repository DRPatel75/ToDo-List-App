# ToDo List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript. This app helps users manage daily tasks efficiently with features like task filtering, completion tracking, local storage support, and task deletion.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Filter tasks:
  - All Tasks
  - Active Tasks
  - Completed Tasks
- Clear completed tasks
- Local storage support
- Responsive UI design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage API
